# Smart Attendance System 🎯

## 📌 Overview
This project is an AI-based Smart Attendance System that uses face recognition to automatically mark attendance.

## 🚀 Features
- Face Detection & Recognition
- Automatic Attendance Marking
- Real-time Camera Integration
- Attendance Record Storage

## 🛠️ Technologies Used
- Python
- OpenCV
- face_recognition
- NumPy

## 📂 Project Structure
Smart-Attendance-System/
│── attendance_excel.csv
│── capture_image_from_camera.py
│── face_app.py
│── requirements.txt

## ▶️ How to Run
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run the project:
   python capture_image_from_camera.py
   python face_app.py

## 📊 Output
- Detects faces
- Marks attendance automatically
